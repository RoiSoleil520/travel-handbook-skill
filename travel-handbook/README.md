# Travel Handbook · 旅行手册模板

把简单的旅游攻略做成旅行手册网页，默认使用苔原绿配色。内置模板保留封面、日期导航、时间线、景点详情、地图与地点复制、出发待办和手机/桌面布局；角色、备选方案及订单卡片按输入内容启用。

## 安装与分享

复制完整的 `travel-handbook` 目录到应用支持的技能目录。例如，Codex 的个人技能目录可使用 `~/.codex/skills/travel-handbook`，项目技能目录可使用 `.agents/skills/travel-handbook`。具体发现和加载方式以本地应用约定为准。

分享时保留 `SKILL.md`、模板、脚本、数据格式说明及检查文件的相对位置，不能只发送 `SKILL.md`。本包不需要原作者的网站、私人攻略、登录账号或云服务配置。

## 直接这样提需求

```text
使用 travel-handbook，帮我把下面的攻略做成旅行手册网页，保留内置模板风格和交互。

杭州 3 日游，2027 年 5 月 1 日出发，两人同行。
第一天：下午到杭州，入住后逛西湖。
第二天：上午灵隐寺，下午龙井村，晚上吃杭帮菜。
第三天：上午逛河坊街，下午返程。
酒店和门票还没订，具体时间待确认。暂时没有图片，可以用示意图。
```

也可以直接附上已有攻略，让 AI 整理。通常只需说明城市、起始日期、同行人和每日大致安排；AI 会生成 `trip.json`，无需自己填大表。未提供的时间、价格与订单信息不会默认视为已确认。

## 选择旅行配色

可在需求末尾加“用粉色”“用夏季主题”或“用暗色”。未指定时默认绿色；不根据旅行日期或系统深色模式自动换色。

| ID | 配色 | 推荐场景 |
| --- | --- | --- |
| `green` | 苔原绿 · 深绿与浅纸绿 | 山野、湖畔、慢旅行，默认配色 |
| `pink` | 春樱粉 · 柔粉与暖白 | 春游、赏花、双人周末 |
| `purple` | 暮山紫 · 灰紫与浅雾色 | 艺术展、古城、城市漫步 |
| `summer` | 夏日海盐 · 青蓝与浅沙色 | 海边、岛屿、夏日度假 |
| `autumn` | 秋日杏茶 · 杏色与茶棕 | 赏秋、古镇、美食之旅 |
| `winter` | 冬日雾蓝 · 雾蓝与雪白 | 雪景、温泉、冬季小旅行 |
| `holiday` | 节日朱砂 · 柔和朱红与米白 | 新年、节庆、团聚 |
| `dark` | 午夜深蓝 · 深蓝底与柔亮文字 | 夜间阅读 |

在原攻略 JSON 的顶层加 `"theme": "pink"` 即可设置默认配色，其余行程字段保持原样。页面封面右上“配色”和旅行工具/桌面侧栏的“旅行配色”支持实时切换，选择按旅行 ID 保存在当前浏览器。生效顺序为：本机选择 → JSON 默认值 → `green`。

配色切换只调整页面颜色，保留布局、日期、行程和照片原色。四季与节日主题是视觉预设，不会修改出发日期或填入节假日安排。

## 国内与国外地图

AI 按实际地点选择地图：中国内地使用高德（`amap`），国外使用 Google Maps（`google`）。可在攻略 JSON 顶层设置 `"mapProvider": "amap"`，每天、事件及具体景点、住宿、接送、自驾、航班机场与铁路车站也能单独覆盖；跨境行程不会统一改成一种地图。

省略配置时沿用上级；每天、事件或航班端点若明确提供当地 `zone`，则按当地时区推断，整程默认按 `timezone` 推断。地点所属区域与地图选择不受浏览器语言或页面显示时区影响，具体规则见[数据格式](references/data-format.md#地图服务与搜索词)。国内搜索词优先用“中文正式名 + 城市”，国外用“当地名/英文名 + 城市”。国内接送只有地点名称时提供“起点地图”和“终点地图”，不编造坐标或已规划路线；国外保留 Google 路线入口。不需要地图 SDK 或 API Key，打开地图仍需联网。

## 内置示例

[完整示例](examples/trip.json) 是“云南五日慢游”：大理 2 天＋丽江 3 天，含天气备选、角色切换和高德地图。首日小禾乘飞机、云舟与阿宁乘高铁、林夕取车自驾，每日行程显示三种卡片，飞机与高铁在“交通住宿”汇总，自驾在“交通接送”汇总；查看身份可切到全体或各自交通组。人物、班次、航站楼、座位、交通时刻与费用全部为虚构演示，并非实际订单。

景点背景来源见页面“行程总览”；2027 年 4 月 3—7 日仅作演示，住宿、交通与门票未预订。示例保留核实到的景点公开票价，在费用预算附查询日期与官方来源；套票、基础费用和可选项目分开说明，不与虚构交通价格混算。生成自己的攻略时替换示例数据并重新核价，不照搬日期或订单状态。

## 同行人分别抵达

可以直接描述：“小禾坐飞机，云舟和阿宁坐高铁，林夕开车，在酒店会合。”再提供已确认的交通资料，AI 会分别建立事件，共同行程保持所有人可见。

- 飞机：航班号、航空公司、乘机人、出发/到达机场与航站楼、当地日期时间、费用和状态；显示深色航班卡与计划倒计时。
- 高铁：车次、乘车人、车站与当地时间、席别、车厢、每人座位和检票口；运行时长由起止时间计算。
- 自驾：起终点、同行人、出发时间与预计用时；租车可补取车时间、取车地点和车辆，自有车辆不用填取车信息。

三种交通统一使用深色卡片，并跟随旅行配色。飞机与高铁分别显示计划起飞、计划发车倒计时；高铁发车后显示计划已发车或计划已抵达，不代表实时运行状态。自驾保留预计用时，不显示倒计时。

未知班次或时间保留普通待定事件；未知座位与检票口留空或待确认。姓名只用于展示，身份切换不提供隐私保护。天气备选也会保留各自交通安排；完整字段见[数据格式](references/data-format.md#事件)。

## 本地生成

需要 Node.js 18 或更新版本。数据字段见 [references/data-format.md](references/data-format.md)，可参考 [最小示例](examples/minimal.json) 和 [完整示例](examples/trip.json)。在本 skill 目录中执行：

```sh
node scripts/build.mjs --input /path/to/trip.json --output /path/to/new-trip-site
```

自带图片时，数据中的路径写为 `assets/custom/lake.jpg`，图片目录中放 `lake.jpg`，再执行：

```sh
node scripts/build.mjs --input /path/to/trip.json --output /path/to/new-trip-site --assets /path/to/photos
```

这些路径仅为示例，请换成自己的文件位置。使用新输出目录。若已安装 Python 3，可运行 `python3 -m http.server 8000 --bind 127.0.0.1 --directory /path/to/new-trip-site`，在浏览器打开 `http://127.0.0.1:8000`。也可使用已有的静态预览工具。分享或部署时带上整个输出目录。

## 自检与限制

在本 skill 目录运行：

```sh
node tests/check.mjs
```

浏览器自动检查为可选项，需要已安装 Playwright 及 Chromium：`node tests/verify-ui.mjs`。也可设 `PLAYWRIGHT_MODULE_PATH` 指向已有模块、`PLAYWRIGHT_CHANNEL=chrome` 使用本机 Chrome；`TRIP_UI_SCREENSHOT_DIR` 可保存截图。交付前还应实际查看手机和桌面尺寸，检查日期切换、详情返回、待办保存与地图入口。

待办和偏好保存在本机浏览器；不内置多人云同步、账号或访问控制。离线功能需首次联网加载，且通过 HTTPS 或本地服务使用；地图链接仍需联网。静态输出是明文，分享前检查个人信息与订单内容。占位图仅作示意，可换为自己有权分享的图片。
